# Bayesian-spatiotemporal-modeling-project
Bayesian Spatio-Temporal Modeling and Change Point Detection of Energy Consumption in the Midwestern United States
The R code covers the following sections:
✅ Data preprocessing
✅ Spatial adjacency matrix (Queen contiguity)
✅ Pettitt classical benchmark
✅ Bayesian Online Change Point Detection (BOCPD)
✅ Bayesian spatio-temporal hierarchical model (CAR + Random Walk)
✅ Posterior predictive checks
✅ WAIC + LOO-CV
✅ State-wise visualization with uncertainty bands
